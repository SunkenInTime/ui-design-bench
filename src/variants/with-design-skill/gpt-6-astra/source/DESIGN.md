# Morrow: five places for a second brain

Morrow is a personal note-taking space for curious people: save a passing thought, collect references, and rediscover connections. The landing pages should make the feeling of using the product tangible. All five routes share this product story, a working local notebook, and a small route switcher.

## One: the thought garden

- Palette: mist `#F3F7F0`, forest `#193E2B`, leaf `#B9CD9D`, lilac `#E4DFF0`, paper `#FFFFFF`.
- Type: Bricolage Grotesque for generous, organic headlines; DM Sans for interface and prose.
- Layout: left-aligned oversized headline beside a branching composition of real notes; a horizontal feature index leads into a working notebook.
- Principle: the mind as something to tend. Botanical shapes belong to the note graph, with no unrelated decorative scenery.

```text
logo                       navigation       start
large headline             connected notes
support / start            botanical graph
                 capture / connect / return
                 interactive notebook
```

## Two: the electric workspace

- Palette: cobalt `#2448E8`, chalk `#FAFBFF`, lemon `#F7EE96`, periwinkle `#BCC8FF`, ink `#1D2860`.
- Type: Bricolage Grotesque at poster scale; DM Sans for small functional details.
- Layout: tight, left-aligned three-line headline and a large tilted application window, followed by a full-width white workflow section.
- Principle: turn cognitive overload into creative energy. The main visual is an actual browsable inbox, with a clipped yellow reminder.

```text
logo                   navigation          start
bold three-line title       large app window
start / demo                overlapping note
             statement band
capture panel               connected panel
```

## Three: the quiet library

- Palette: pearl `#F8F6FB`, aubergine `#48384F`, lavender `#DED4E9`, rose `#F0DEE1`, page `#FFFFFF`.
- Type: Instrument Serif for literary display; DM Sans for the library interface.
- Layout: centered, spacious title over a fan of three large archival note pages; a left-aligned reading room below.
- Principle: a place for the thoughts worth returning to, with the tactile calm of a personal library.

```text
logo                  navigation             start
                 centered serif title
                     supporting copy
              page / page / page
          reading room / searchable notes
```

## Four: the connection map

- Palette: plum `#2B2036`, blush `#F4C5D6`, mint `#C7DDCF`, violet `#9584AF`, deep plum `#372A43`.
- Type: Space Grotesk for clear, distinctive headings; DM Sans for the working graph.
- Layout: left-aligned title shares a wide dotted canvas with a live constellation; selected nodes reveal a note in an anchored panel.
- Principle: let the relationships be the spectacle. No ambient animation or decorative gradients.

```text
logo                   navigation            start
headline           topic ---- topic
support                 \ central note
start               topic ---- topic
            selected connection details
```

## Five: the open pinboard

- Palette: peach `#FFF0E8`, cherry `#602D3D`, tangerine `#ED6945`, butter `#FAE69A`, lilac `#DAD1F0`.
- Type: Space Grotesk for an oversized friendly title; DM Sans for notes; Caveat for handwritten scraps.
- Layout: centered heading surrounded by an asymmetric, movable collage of ideas; useful controls sit at the base of the board.
- Principle: an accommodating home for unfinished thoughts. A deliberately untidy canvas inside disciplined page spacing.

```text
logo                 navigation               start
    note          giant headline           photo
scrap                 start                  list
         note     interactive pinboard    note
                  add / rearrange
```

## Review before implementation

The first draft of the garden used a generic feature-card grid; replace it with a single growing note graph and a useful feature index. The blue direction initially used a large abstract blob; replace it with the product itself, an interactive inbox. Keep the quiet library lavender rather than the familiar cream/terracotta combination. The dark route uses a clearly plum surface and multiple semantically colored note families. The pinboard must allow real rearrangement, rather than suggesting functionality through static decoration. Avoid fabricated customer statistics and testimonials. Give every route its own composition and lower-page content, while sharing technical primitives.

## Delivery quality

Responsive layouts, keyboard focus, reduced motion, working navigation and note interactions, persisted local notebook, semantic landmarks, desktop and mobile visual review. All five primary CTAs open the same useful local notebook; no fictional account creation or payment flows.
